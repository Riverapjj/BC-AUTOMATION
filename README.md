# QA Automation Framework

Automation framework for E2E and API testing.

## Technologies

- Java 17
- Maven
- Selenium WebDriver
- TestNG
- Rest Assured

## Test Types

- E2E Testing
- API Testing

## Architecture

The framework uses a domain-oriented structure with a shared core for common automation infrastructure.

## GitFlow

The project follows a GitFlow-based branching strategy:

- `main`
- `develop`
- `feature/*`
- `release/*`
